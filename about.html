How this site stays alive

  • Events live in a shared Google Sheet, not in the code. Anyone on the team can add a row, with no coding needed.
  • Past events disappear by themselves, so the list doesn't go stale.
  • Anyone can suggest an event through our form.
  • It's free to host on GitHub Pages, with no servers to pay for.
